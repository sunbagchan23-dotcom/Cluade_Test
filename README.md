# 화면 OCR 시험 앱 (1단계)

화면 방송 중 N초(기본 5초)마다 한 프레임을 한국어 OCR하고, 인식 텍스트·확장 메모리·배터리를 로그로 남깁니다.
목적은 두 가지 확인입니다.

1. 방송 확장의 메모리 한도(약 50MB) 안에서 OCR이 죽지 않고 계속 도는가
2. 배터리 소모가 감당할 만한가

일정 추출·캘린더 연동은 아직 없습니다.

---

## 설치 방법 (윈도우 + 아이폰, 무료 Apple ID)

### 준비물 (처음 한 번)

1. **iTunes**와 **iCloud**를 애플 홈페이지에서 받아 설치합니다.
   마이크로소프트 스토어 버전이 아니라 애플 사이트의 "다운로드" 버전이 안전합니다. (Sideloadly가 이 버전을 권장)
2. **Sideloadly**를 https://sideloadly.io 에서 받아 설치합니다.
3. 아이폰을 USB로 PC에 연결하고, 아이폰에 "이 컴퓨터를 신뢰하겠습니까?"가 뜨면 **신뢰**를 누릅니다.

### 앱 파일(IPA) 받기

1. GitHub 저장소 페이지 → 위쪽 **Actions** 탭
2. 맨 위의 초록색 체크(✓) 실행을 누름
3. 아래 **Artifacts**의 `ScreenOCRTest-ipa`를 눌러 내려받음 (zip)
4. zip을 풀면 `ScreenOCRTest.ipa`가 나옵니다

### 아이폰에 설치

1. Sideloadly 실행 → 왼쪽 위 IPA 칸에 `ScreenOCRTest.ipa`를 끌어다 놓기
2. **Apple account** 칸에 Apple ID 이메일 입력 → **Start**
3. 비밀번호와 (뜨면) 2단계 인증 코드를 입력
4. "Done"이 뜨면 설치 완료

### 아이폰에서 처음 실행 전에 (처음 한 번)

1. **설정 → 개인정보 보호 및 보안 → 개발자 모드** 켜기 → 재시동 → 켜기 확인
   (메뉴가 안 보이면 Sideloadly 설치를 한 번 한 뒤 다시 보세요)
2. **설정 → 일반 → VPN 및 기기 관리** → 내 Apple ID 항목 → **신뢰**

### 7일 제한

무료 Apple ID로 설치한 앱은 **7일 뒤 열리지 않습니다.** 위 "아이폰에 설치"를 다시 하면 로그는 그대로 두고 갱신됩니다.

## 시험 방법

1. 앱 실행 → 맨 아래 **진단**에서 "공유 폴더 접근: 성공"인지 확인 (실패면 아래 "문제 해결" 참고)
2. **1. 화면 방송**의 둥근 버튼 → "OCR시험 방송" 선택됨 확인 → **방송 시작**
3. 평소처럼 카톡·메일·브라우저를 30분~1시간 사용
4. 화면 위 빨간 표시(또는 제어 센터 화면 기록 버튼)로 방송 중단
5. 앱으로 돌아와 **3. 마지막 방송 요약** 확인 → 오른쪽 위 공유 버튼으로 로그 파일 내보내기

### 요약 보는 법

| 항목 | 좋은 신호 | 나쁜 신호 |
|---|---|---|
| 최대 메모리 | 40MB 이하 | 45MB 이상 (한도 근처) |
| 한도까지 최소 여유 | 10MB 이상 | 5MB 미만 |
| 종료 기록 | 정상 종료 | "없음"인데 방송이 저절로 꺼졌다 → 메모리 초과로 강제 종료됐을 가능성 |
| 배터리 소모 | 방송 안 할 때보다 시간당 몇 %p 차이 | 시간당 10%p 이상 추가 소모 |
| OCR 평균 시간 | 간격(5초)보다 충분히 짧음 | 간격에 가까움 |

메모리가 빠듯하면 **축소 비율**을 50%·40%로 낮춰 다시 시험하세요. 글자가 잘 안 읽히면 75%로 올려 비교합니다.

## 문제 해결

- **공유 폴더 접근: 실패**
  무료 계정 서명 과정에서 App Group 권한이 빠진 경우입니다. 이때 방송 확장은 기록은 하지만 본 앱이 읽을 수 없습니다.
  1순위 대안: Sideloadly 대신 **AltStore**로 설치 (AltStore의 서명 코드에는 App Group을 무료 계정에 등록하는 기능이 들어 있음. 다만 이 앱으로 직접 확인한 건 아님).
  2순위 대안: 99달러 개발자 계정.
- **방송 목록에 "OCR시험 방송"이 없음**: 앱을 지웠다 다시 설치하고, 아이폰을 재시동해 보세요.
- **방송이 몇 초 만에 저절로 꺼짐**: 메모리 초과 가능성이 큽니다. 축소 비율을 40%로 낮추고 다시 시도한 뒤 로그를 공유해 주세요.

## 개발자용 메모

- 맥 없이 빌드: `.github/workflows/build.yml`이 GitHub의 macOS 서버에서 XcodeGen으로 프로젝트를 만들고 서명 없이 빌드한 뒤, App Group 권한만 임시 서명으로 넣어 IPA를 만듭니다.
- 무료 계정 사이드로딩 도구는 번들 ID와 App Group ID를 바꿀 수 있어, 코드는 둘 다 실행 중에 실제 값을 읽습니다 (`embedded.mobileprovision`, `PlugIns` 폴더).
- 메모리 절약: 처리 중엔 프레임 버림, YUV의 밝기 평면만 CPU(vImage)로 축소, 축소 버퍼 재사용, `autoreleasepool`.
- 로그 형식: App Group 폴더의 `ocr_log.jsonl` (한 줄에 JSON 하나). `kind`: start / ocr(내용 바뀜) / same(이전과 같음, 텍스트 생략) / beat(1분마다) / pressure(메모리 경고) / error / stop.
